这个问题问得非常深刻，直击线性代数中“对称性”最核心的魔法。

直接回答你的核心困惑：**因为实对称矩阵的零空间（特征值0对应的特征子空间）和列空间（值域）是“正交互补”的，这迫使零空间的维度恰好填满特征值0的重数，不会出现“缺维”的情况。**

为了让你彻底看透“为什么”，我们拿**不可逆的非对称矩阵**做对比，漏洞一目了然。

---

### 1. 直观对比：为什么非对称矩阵会“缺维”？
看这个经典的不可逆矩阵（若尔当块）：
$$
A = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}
$$
它的特征值是 $ 0, 0 $（代数重数 $ AM = 2 $）。

- **几何重数（$ GM $）**：解 $ Ax = 0 $，得到 $ y = 0 $，特征向量只能是 $ (x, 0)^T $，只占一条直线，所以 **$ GM = 1 $**。
- **为什么缺了？** 因为矩阵把 $ (0, 1)^T $ 映射到了 $ (1, 0)^T $，而 $ (1, 0)^T $ 恰好也在零空间里。这意味着**列空间（值域）和零空间发生了重叠**，零空间被“压扁”了，维度凑不够 2。

---

### 2. 核心证明：对称矩阵为什么不会“重叠”？
对于实对称矩阵 $ A = A^T $，有一个极其漂亮的几何性质：

**实对称矩阵的零空间（$ N(A) $）与列空间（$ C(A) $）是相互正交的。**

证明很简单：
- 任取零空间中的向量 $ x $（即 $ Ax = 0 $）；
- 任取列空间中的向量 $ y $（即存在 $ z $，使得 $ y = Az $）；
- 计算内积：$ x \cdot y = x^T (Az) = (A^T x)^T z = (Ax)^T z = 0^T z = 0 $。
因为内积为 0，所以它们垂直。

**关键逻辑来了：**
在线性代数中，对于 $ n $ 维空间，无论任何矩阵，都有 **秩-零化度定理**：$ \dim(N(A)) = n - \text{秩}(A) $。
既然零空间和列空间正交，且它们维度之和正好等于 $ n $（因为 $ \dim(C(A)) = \text{秩}(A) $），那么它们俩恰好瓜分了整个 $ n $ 维空间，没有任何重叠和浪费。

---

### 3. 把这个性质“装进”特征值重数里
现在设矩阵的秩为 $ r $（因为不可逆，所以 $ r < n $）。

- 零空间的维度是 $ n - r $，这意味着 **特征值 0 的几何重数 $ GM = n - r $**。
- 因为零空间和列空间正交互补，我们可以在列空间里找到 $ r $ 个非零特征向量（对应非零特征值），在零空间里找到 $ n-r $ 个零特征向量。合起来正好 $ n $ 个线性无关的特征向量。

**最关键的一步（代数重数的计算）：**
我们把整个空间按“零空间 + 列空间”拆开，在这组基下，矩阵 $ A $ 可以被写成分块对角形式：
$$
A = \begin{pmatrix} B & 0 \\ 0 & 0 \end{pmatrix}
$$
其中 $ B $ 是 $ r \times r $ 的可逆矩阵（在列空间上），右下角的零块大小是 $ (n-r) \times (n-r) $（在零空间上）。

计算特征多项式 $ \det(\lambda I - A) = \det(\lambda I_{r} - B) \cdot \lambda^{n-r} $。
因为 $ B $ 可逆，$ \det(0 \cdot I - B) 
eq 0 $，所以特征值 0 的幂次恰好是 $ n-r $。
**这意味着特征值 0 的代数重数 $ AM = n-r $**。

---

### 4. 结论对撞
- **非对称矩阵（如若尔当块）**：列空间和零空间有重叠，无法拆成干净的分块对角，导致零空间维度（$ GM $）小于零特征值的重数（$ AM $）。
- **实对称矩阵（无论是否可逆）**：正交性强行把空间拆成互不干扰的两部分，使得 **$ GM = AM = n - \text{秩} $**。

所以，实对称矩阵不可逆，并不影响它的“健康”——它只是把特征值 0 老老实实地放在对角线上，重复 $ n-r $ 次，并且恰好有 $ n-r $ 个相互垂直的零特征向量撑起零空间。这也就是为什么**所有实对称矩阵（无论是否奇异）都可以完美地进行特征分解（正交对角化）**。
